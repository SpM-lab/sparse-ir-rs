# sparse-ir-sve

The singular value expansion (SVE) of integral kernels K(x, y), computed in
extended precision, and the numerics it is built on. It is the lowest layer
of [`sparse-ir`](https://crates.io/crates/sparse-ir) and knows nothing about
statistics, temperatures or Matsubara frequencies, so it can be used for
other kernels as well.
